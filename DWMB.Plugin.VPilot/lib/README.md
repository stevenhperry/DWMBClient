# vPilot plugin SDK

`RossCarlson.Vatsim.Vpilot.Plugins.dll` is not distributed via NuGet -- copy it
into this folder from your local vPilot installation (the same folder vPilot.exe
lives in) before building. This matches how existing open-source vPilot plugins
(e.g. [vPilot-Pushover](https://github.com/blt950/vPilot-Pushover)) do it.

This file, and this folder, are gitignored except for this README -- the DLL
itself is never committed (see `../../.gitignore`).
