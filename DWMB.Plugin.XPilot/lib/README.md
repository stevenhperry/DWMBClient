# xPilot plugin SDK

`xPilot.PluginSdk.dll` is not distributed via NuGet. Build it yourself from
[xpilot-project/plugin-sdk](https://github.com/xpilot-project/plugin-sdk) (`dotnet
build xPilot.PluginSdk.csproj`), or copy the DLL out of an existing xPilot
installation, and drop it into this folder before building.

This file, and this folder, are gitignored except for this README -- the DLL
itself is never committed (see `../../.gitignore`).
